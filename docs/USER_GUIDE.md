# TabLens 使用手册

TabLens 把六线谱图片变成可编辑、可播放的 TAB，也可以从空白乐谱开始编曲。本手册按实际操作顺序说明。安装与启动方式见 [README](../README.md)。

## 认识工作台

顶部是“新建”“乐谱库”“导入谱图”“打开文件”“保存”等入口；本机自带谱例也在“乐谱库”中。TAB 从左到右依次演奏，同一列的多个数字表示同时弹的音。右侧“音符 / 节奏 / 表现 / 小节”用于编辑音高、时值、力度和小节。

顶部重叠纸张图标是“另存为”，向下箭头是“导出”。右上角半圆图标可快速选择跟随系统、浅色、深色或自定义主题；齿轮图标打开设置。把鼠标停在图标或 TAB 标题旁的问号上，会出现操作说明；用键盘选中它们也能查看。面板之间的细分隔线仍可拖动，调整 TAB 与右侧工作区、原图与编辑区的大小。

工作台上方的标签可在多首乐谱之间切换，橙色圆点表示这首谱还有未保存的修改。点标签左侧的文件夹图标可展开文件栏，查看已打开的标签、乐谱库文件和本机暂存；再次点击或点文件栏的叉号可收起。切换标签会保留各自的选中位置、撤销记录和练习范围；刷新页面会重新打开之前的标签。

标题旁的“校谱 / 练习 / 编曲”是三个可点击、可拖动切换的模式按钮，切换时按钮位置保持不变。校谱默认 TAB 占左侧整高，原图和编辑工具上下排列在右侧。点击 TAB 标题的“工作区右侧”，可改为原图与 TAB 上下排列在左侧、编辑工具占右侧整高；再次点击可恢复默认位置。拖动三个面板标题左侧的手柄到“左/右侧整高、上方、下方”目标区，也能自行调换位置；点击手柄可直接选择目标，按 Esc 可取消。拖动分隔线调整两侧宽度和上下高度，设置中的“恢复默认布局”会同时恢复位置和尺寸。

练习时，有原图的小节会将原谱放大放在左侧，右侧保留可点击的 TAB 和逐音光标。旁边固定的“原图 / TAB”按钮可选择哪个作为主视图，拖动两栏之间的分隔线可调整宽度。没有原图的小节会自动用全宽 TAB 跟练；编曲模式隐藏原图。校谱面板的停靠只影响校谱模式，布局偏好只保存在当前浏览器，不写进乐谱文件。

整谱播放前，先确保每个演奏位置都有明确的音符或休止、并设好节奏。你可以随时用“试听当前位置”检查单列声音。

## 导入图片或 PDF

1. 点击“导入谱图”，选择 PNG、JPG、WebP 或 PDF。PDF 先在“PDF 页面”中选一页，再处理该页；原始 PDF 不会随乐谱保存，选中的页面图像可用于后续原图对照。
2. 点击“分析图片（不调用模型）”。这一步只在本机寻找 TAB 段落。候选结果会显示定位总数、已识别数和待补录数；橙色框代表尚未读出音符，可点“查看原图”定位。若发现整段小节漏定位，点“补漏小节：在原图框选”，拖动框住一个完整小节，再点“加入候选小节”。可自动按原图顺序排列，也可指定插在某段之前。能定位弦线和演奏位置的补漏段可继续勾选识别；否则保留原图，打开后手动补录。每次框一个小节，可重复补漏；即使整页自动分析失败，也可直接框第一个小节。
3. 在“识图 API 设置”填入支持图片输入的接口地址、模型名和密钥，点击“连接 / 更新设置”。设置完成后，勾选要读的小节，点击“开始识别所选小节”。调用可能产生服务商费用；取消任务不会撤回已发出的请求。
4. 先检查候选 TAB。点击候选数字，可在原图上看对应位置。未勾选、识别失败或不适合自动识别的已定位段落会保留为空小节。确认无漏段后点“作为新谱打开”；续页可点“追加到当前谱”。
5. 需要局部修正时，在右侧“小节”页点“重新识别当前小节（先预览）”，检查候选后仅替换该小节；空小节也可在这里重试，或直接对照原图补录。若整页布局不适合逐小节框选，仍可点“本页作原图，建空小节”手动录入。

识图密钥仅保存在本机服务的内存中，重启服务后需重新输入；不会写进乐谱文件。完整操作后仍要核对弦号、品位、先后顺序和同时弹组合，尤其留意候选中标出的不一致之处。

## 打开文件或新建乐谱

“打开文件”可读取 TabLens 导出的 `.tablens.json`，也可读取符合 [Agent 读谱模板](../AGENT_IMPORT_TEMPLATE.md)的 JSON。把模板和谱图交给能读取图片文件、运行代码的 Agent，它可生成包含原图的 `tablens.agent.v2` 文件：每个小节有独立的原图范围，范围内可保留六线谱及其下方歌词。Agent 文件也能记录明确标出的击弦、勾弦、滑弦和只扫部分弦的动作。打开后先逐小节检查原图是否截对，再查看“校对提示”并逐音核对技巧连接、实际扫到的弦和节奏。这里的歌词只是图片，不会变成可编辑文字；小节原图范围也不等于逐音像素定位。旧版 `tablens.agent.v1` 文件仍可打开，但不自带原图，可在“小节”页手动关联。

点击“新建”会得到一个空小节。在空小节的弦线上点击，建立第一个演奏位置，再输入品位；之后可在末尾的加号继续添加位置。没有原图也能写谱。右上角“设置 → 新建乐谱”可预先设置空白谱的 BPM、拍号、变调夹和延音方式；新建窗口会显示即将使用的值。它们只在创建时写入新谱，不覆盖打开或导入的乐谱。新谱目前固定采用标准六弦调弦。写作过程中仍可修改标题、拍号、BPM 和变调夹。

## 校对与编辑 TAB

**单音。** 点击数字或同列空白弦格即可选中；再次点击同一格，或直接键入数字，在谱上填写 0–36 品。按 Enter 确认、Esc 取消。选中后按 Backspace 删除该音；在输入数字时，Backspace 只删输入框里的字符。需要改弦号时，使用右侧“音符”页。

校谱模式默认使用紧凑谱面；点 TAB 标题旁的“紧凑谱面”可切回标准大小。这个选择只改变当前浏览器里的显示，不修改乐谱，练习模式仍使用标准谱面。右侧“音符”页的“基础 / 连接 / 倚音 / 推弦 / 和弦”是一排固定入口，点开一项就显示对应参数；连续选中别的音符时会保留正在查看的效果控件。“基础”可立即返回弦和品位。鼠标停在四个编辑页签上可查看各页用途。

**同时弹与演奏位置。** 在同一列的另一根弦上填写品位，就是同时弹。点击位置编号或列框顶部选中整列，可在前后插入或删除演奏位置；在小节最后一个位置右侧也有加号。选中整列再按 Backspace，会删除整个位置。相邻位置可以合并成同时弹；也可把选中的音拆到下一位置。合并、拆分后请复核时值。

**休止。** 先选中一个没有音符的位置，在“节奏”页点“将空位置设为休止”。点“移除休止符”只清除休止标记，位置与时值仍在；要一起删除，点“删除当前位置”。

**小节。** 点击小节标题、边缘或内部空白选中小节；小节之间的加号可直接插入，小节标题的叉号可删除。在右侧“小节”页也可前插、后插或复制。打开“小节总览”，拖动左侧把手调整顺序，并可在那里新增、删除。增删后小节编号会重新连续排列。

**左右键。** 点选整个演奏位置后，按 ← / → 选择前一个或后一个位置，可以跨小节；点选单个音符后，左右键会在前后位置继续定位同一根弦，目标位置没有该弦音符时会选中空弦格，方便直接输入品位。选中小节时，左右键改为选择前后小节，包括空小节。到全谱边界就停下；这些按键只在六线谱获得焦点时导航，不会抢走输入框、模式按钮或弹窗的左右键，也不会改变正在播放的位置。

**多选。** 在 TAB 空白处拖动框选；按住 Ctrl 点击可增减选择，先点起点再按住 Shift 点击终点可选连续位置。谱上方会出现改时值、改力度和“删除所选音”。这些操作都可撤销；快捷键是 Ctrl+Z，重做是 Ctrl+Shift+Z。

**校对提示。** 校谱模式底部展开后，逐项列出未知品位、未知节奏、未知演奏位置、拍数不符和导入时留下的疑问。点击问题或“下一项”，会定位到相应音符、演奏位置或小节；没有逐音原图坐标时只显示该小节原图。处理完明确问题后，仍需对照原谱检查每个导入小节的弦、品、先后顺序和同时弹组合，再点“标记已核对”。标记会随乐谱保存；之后修改该小节的乐谱内容，会显示“修改后待复核”。自动提示为空不代表模型识别一定正确。自编空白小节不要求逐节确认。练习模式会隐藏这份清单。

## 设置节奏和演奏方式

点击 TAB 下方的节奏符号，或在右侧“节奏”页修改当前演奏位置的时值；同一列的音共用这一时值。问号表示未设节奏，不会被自动猜成四分或八分。多个位置需要同样时值时，在“练习 / 批量设置”中选择范围并应用。拍号不匹配会提示；弱起或不完整片段可在“小节”页标记为允许不足。

同时弹的多音位置可以在“节奏”页设为**下扫或上扫**，并选择自动、快、标准或慢的扫过时间。只扫部分弦时，该位置只保留实际弹响的音符。不设置扫弦就仍是同时起音；连续上下扫要分别放在多个演奏位置。新建扫弦和 Agent 导入的扫弦默认快扫偏轻，标准和慢扫为中等力度；“表现”页可改为固定的轻、中、重，也能切回自动。右上角“设置”可调整自动扫弦的拍点起伏，默认“标准”，也能选原来的“轻微”效果、关闭或更明显；旧谱会在下次播放时一同生效，手动调过的单次扫弦力度保持原值。箭头旁的短条表示相对强弱，关闭起伏时不显示。本地吉他音色的上扫使用较轻的采样，同时保留短促起音和持续到下次同弦触弦的声音；缺少轻奏音源时使用原有音色。“音符”页有常用和弦指型，可填入当前列，再逐弦调整并核对和弦名。填入会替换当前列音符，复制到下一位置也会替换下一列音符，操作前可先保存。

击弦、勾弦和滑弦从前一颗同弦音连接到选中的目标音，可在“音符”页设置；滑弦还能调快慢。Agent 读谱模板允许明确写入这三种技巧，导入时会检查连接；自动图片识别仍不会可靠填写。短前倚音和推弦目前在该页手动添加。“表现”页可调整整个位置或单颗音的轻重，以及该位置的延音方式。

## 播放与跟练

点击“播放”从当前练习范围开始，播放中同一按钮变成“暂停”，再点可继续。“从选中位置播放”从选定位置起步，“停止”结束播放；橙色光标跟随当前音符。整谱若有未知品位或未设时值，播放会定位到需要修改的位置；此时仍可用“试听当前位置”检查已知的音。

顶部可改 BPM 和变调夹。“练习 / 批量设置”里可选起止小节、循环、0.75× 或 0.5× 速度、开始前数 4 拍和节拍器。“设置 → 练习习惯”可指定速度倍率、数拍和节拍器的初始状态；保存后立即应用到当前练习，之后打开乐谱也会采用。练习范围和循环仍由每次练习选择。音色可选本地吉他采样或基础合成拨弦；全谱延音可选自然延音或按时值止音。自然延音下，同弦新音会接替旧音，其他弦的声音继续衰减。音量可直接在工作台调整。

练习时可在“设置 → 练习习惯”分别调整“练习时原图跟随”“显示后续原图”和“双图排列”。默认逐小节：主图显示当前小节，下方预览包含下一小节的完整谱行。整行跟随时，主图显示当前谱行，同一行内保持图片位置不变，只更新音符高亮；预览显示**下一谱行**，不会重复当前行。到最后一行时没有后续内容，预览自动收起。关闭“显示后续原图”即可只看主图；开启后可选上下或左右排列。左右排列用于原图占主视图且窗口够宽的情况；原图在窄侧栏时自动上下排列。“上一行 / 下一行”仍可手动浏览预览。谱行按原图排版划分，不固定为四小节；无法确定谱行时主图仍显示当前小节。两块原图分别支持滚轮或 `－ / ＋ / 适应`缩放、拖动移动；Ctrl＋滚轮仍交给浏览器。显示偏好保存在当前浏览器，不写入乐谱。

## 保存导出与恢复

- **保存**：写入项目的 `乐谱库/`；再保存会更新同一文件，并保留上一次备份。文件若已被其他窗口修改，应用会阻止直接覆盖。
- **多首谱**：新建、打开文件和另存为会建立新标签；点标签切换，按 Ctrl+S 保存当前标签。关闭有未保存修改的标签时，可以“保存并关闭”“暂存并关闭”“放弃修改”或“取消”。暂存后可从左侧文件栏或乐谱库找回；放弃修改会清除这首谱的本机暂存，乐谱库里已经保存的版本仍在。
- **另存为**：生成一份可独立编辑的编曲。**导出**：下载包含原图和修改的 `.tablens.json`，便于转移或备份；之后用“打开文件”重新导入。
- **乐谱库**：打开已保存文件或“本机自动暂存”，可按歌名搜索、按修改时间筛选与排序。忘记保存时，先到这里找暂存；重新打开同一文件也会尽量保留不同的未保存修改供恢复。
- **删除**：已保存的乐谱会先移到 `乐谱库/.回收站/`；“删除暂存”只清除浏览器中的那份恢复副本。删除前核对按钮旁的文件名称。

自动暂存依赖当前浏览器的本机数据，重要作品仍应点击“保存”或“导出”。右上角“设置”分为外观与工作区、播放与表现、练习习惯、新建乐谱。在“外观与工作区”里可选方正或柔和控件；自定义主题可分别保存深色底、浅色底的背景色，以及共用的强调色。选择的背景色会自动调整到便于阅读的明暗范围；主题和圆角只保存在当前浏览器，不写进乐谱，也不会改变原图。新建默认值只在创建时写入新谱。

## 识别边界与常见情况

当前自动识别主要适合**清晰、水平、电脑排版、六根弦且有下方符干**的数字 TAB。无符干长音、截断末行、特殊排版、多声部和复杂技巧可能无法识别；基本节奏、休止与技巧也不会稳定地从图片自动恢复。已被本地定位但没识别的段落会保留为空小节；如果整段谱线或小节边界都没被定位，数量统计也看不到它，仍需人工对照整页原图并补建小节。误定位成小节的空段落可在校对后删除。

若识别候选的弦号或品位不对，先对照右侧原图逐音修改；若节奏显示问号，按谱图上的符干与横梁手动设时值。若“打开文件”没有自动跳到项目目录，这是浏览器文件选择窗口的行为；已经保存的作品可直接从“乐谱库”打开。
