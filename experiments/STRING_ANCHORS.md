B 与 C 的 y 坐标相同，C 加左右边距，不改变原图纵向位置。标签、短线都画在新边距里，原谱区域像素不变。但 C 的图片总宽度也随边距增加，不能严格区分边距、服务商图像处理与标签各自的作用；若 C 有效，可追加空白边距对照。D 裁剪保留当前弦的完整字符和少量邻弦边缘残片，中央目标弦与条带弦号由程序指定；提示词要求排除边缘残片。D 不能严格区分图片拆分和提示词改变的单独作用。

辅助图只依据长水平线的位置，不使用正确品位、正确音符个数、人工标注数字或参考乐谱生成图像。生成坐标记录在 `samples/lullaby_string_anchors.json`，源图未修改。

横线检测仅适用于当前清晰水平谱行：灰度阈值加横向覆盖率筛选，合并邻近行像素，要求恰好六组、间距接近。它不是手机拍照、倾斜谱页或任意排版的完整解决方案。

每轮最多四次，不自动重试。新报告保存实际输入图片副本、尺寸、摘要和实际提示词。程序测试验证的是输入保存、像素保留、检测失败处理和调用流程；API 识别效果须实际运行后判定。
