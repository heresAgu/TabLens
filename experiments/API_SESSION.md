# 本地实验会话

打开`启动自动实验会话.cmd`，在掩码输入框输入服务商API密钥，点击“连接实验会话”。密钥只保留在此窗口的内存中。连接时不预先验证密钥，实际请求会进行服务商身份验证；窗口会启动已排队的实验，按服务商用量计费。

Codex只写`control_request.json`，其中只有随机任务id、实验模式、轮数，不包含密钥。每个任务最多2轮，每轮最多4次API请求；格式或网络失败停止后续轮次，不自动重试。每个随机id在执行前登记，已有登记不会在重开窗口后再次执行；需要新的任务id发起新的实验。

任务结果保存在`control_results/`，会话状态在`session_status.json`，实际实验报告仍在`runs/`。状态只记录是否存在内存中的会话密钥，不记录密钥值、片段或摘要。模型返回及显示消息继续由实验程序脱敏。

每个任务执行前重新加载实验程序与依赖。提示词或实验代码更新后，保留此会话窗口即可，通常无需重新输入密钥。窗口断开会停止后续请求并忘记会话密钥；已经发出的网络请求仍可能由服务商处理。关闭后再次使用需要本地重新连接。

原来的手动实验窗口也会在首次运行后保留会话密钥，即使输入框被清空，后续点击开始仍会复用。现在已增加可见说明和复用日志。输入缓存命中与本地会话密钥保留是不同的事情：前者是服务商复用输入计算，后者是客户端继续进行身份验证。

密钥不要写进任务、源码、报告或聊天；若已经发到聊天或其他记录中，建议在服务商后台撤销后换新密钥。连接后Codex可继续发起用户已授权范围内的实验，密钥无需传回Codex。
