# TabLens

把识别得到的吉他六线谱变成可编辑、可跟练的乐谱。当前支持 TAB 编辑、节奏设置和播放跟随。

## 从 GitHub 克隆后

先安装 Python 依赖：`python -m pip install -r requirements.txt`。Windows 可双击 `启动TabLens.cmd`，也可运行 `python app/server.py --open-browser`；打开地址为 `http://127.0.0.1:8765`。Node.js 仅用于开发测试，测试前运行 `npm ci`。

公开仓库包含程序、提示词／实验代码和播放器实际使用的处理后吉他 WAV 采样。个人乐谱库、识别结果、歌曲图片/PDF/MP3、原始 AIFF 录音和实验输出不上传。克隆后首次打开空白乐谱，默认可用吉他采样播放；采样来源与处理方式见 `AUDIO_CREDITS.md`。切勿把 API 密钥放进代码或提交记录。

## 使用

双击 `启动TabLens.cmd`，浏览器打开本机界面 `http://127.0.0.1:8765`。编辑和播放不需要API密钥；导入新图片并调用识图模型时需要密钥。

- 顶部主题按钮依次切换“跟随系统 → 浅色 → 深色”；选择只保存在当前浏览器，刷新后仍生效。深色模式不会改变原谱图片。
- 如果本机保留了 Duvet 或 Lullaby 的测试素材，右上可选择对应谱例；公开仓库没有这些素材时会从空白乐谱开始。
- 点击“新建”可从空小节开始编曲；点击空小节的弦线创建位置，再填写品位。自编小节不要求原图，可在“小节”页关联原图。
- “小节”页支持在前/后插入、复制、删除小节，均可撤销；复制保留音符、同时弹组合、节奏和原图参考。
- 电脑界面可在“校谱 / 练习 / 编曲”模式间切换；拖动乐谱与右侧工作区的分隔线，或拖动原图与编辑区之间的分隔线。布局保存在本机，不写进乐谱。音符、节奏、表现、小节分别编辑；循环、慢速及批量操作放在“练习 / 批量设置”中。
- 点击数字，在右侧修改弦和品位。点击同列空白弦线可添加同时弹的音。
- 选中演奏位置后，在右侧“音符”页选常用和弦指型，点“填入此位置”即可一次写好各弦品位；可继续逐弦修改或手动改和弦名。“复制到下一位置”会替换下一位置的音符并保留其节奏；到小节末尾则新建一个待设节奏的位置。操作均可撤销。
- 在右侧“节奏”页给至少两颗音的演奏位置设置下扫或上扫，并选择自动、快、标准或慢的扫弦时间。未设置时仍同时弹；连续扫弦需要多个演奏位置。扫弦按方向微调各弦的起音、轻重与触弦包络，不改变这个位置占用的拍数；已有音符力度仍然有效。Agent 导入的扫弦若未指定跨度，速度会按相邻节奏自动建议；手动选定后不再自动改变。
- 单击数字或空弦格选中，再点同一格就原地编辑；也可选中后直接输入品位（支持10、12等两位数），Enter或点击别处确认，Esc取消。普通选中状态下Backspace删除单音，数字编辑状态下Backspace仅删除字符。
- 单个弦格有独立绿色边框，所在列仅有灰色参考框；点击位置编号或参考框顶部横条才选中整列并显示前插、后插、删除按钮。点击节奏符号只修改时值。点击小节标题、边缘或内部空白选择整个小节，不自动选中其中音符。
- 点击演奏位置上方的编号，选中整列；可用出现的按钮在前后添加位置或删除整列，也可按Backspace。小节头尾和间隙的加号直接插入小节，小节标题的叉号删除该小节。
- 小节从1开始编号，增删后连续编号；导入时的原谱编号单独保留，可悬停小节标题查看。
- TAB下方以节奏符号显示时值，点击符号就能修改；八分、十六分等按拍内边界连接横梁。未知节奏显示问号，不自动猜测或凑拍。
- 原图自动显示当前小节，并高亮被识别的数字。改弦后仍能对照原来数字的位置。
- 右侧可为当前演奏位置设置时值。未知节奏不自动补齐。
- 顶部可批量设置未设节奏、当前小节或全谱的时值；修改支持撤销，不改变弦、品位和同时弹组合。
- “试听当前位置”播放该列的全部音符，不要求全谱节奏完整。
- 设置好节奏后点击“播放”，支持暂停、继续和停止。橙色光标、音符高亮与原图跟随当前演奏位置。
- 速度按四分音符 BPM 计算，缺失时使用可修改的练习默认值80；变调夹会改变实际发声音高。
- 选择起始与结束小节，可仅播放这一段；勾选循环后连续重复，支持0.5×、0.75×练习速度，不改写乐谱节奏。
- 可开启“开始前数4拍”和四分拍节拍器。倒数只在首次开始时出现，暂停后继续剩余倒数；循环不重复倒数。
- 空演奏位置可添加音符、删除，或显式设为休止。未知品位及未设置的节奏会阻止整谱播放，并定位需要修改的位置。
- 可在当前演奏位置前或后插入新位置；休止位置的按钮会变成“移除休止符”，移除时保留位置与时值。要连位置一起删，使用“删除当前位置”。
- 音色可选择“本地吉他采样”或“基础合成拨弦”。没有安装本地采样时自动使用基础合成音色；采样首次播放按需加载，优先使用对应弦的音源。
- 全谱默认“自然延音”：其他弦开始弹奏及休止位置不会截断前音，同弦新音接替旧音。可切换“按时值止音”，或在右侧单独设置当前位置的延音处理；设置支持撤销和随文件保存。
- 非循环播放结束后保留尾音并显示“尾音自然衰减中”；循环在段落边界淡出旧尾音，避免叠加到下一遍。暂停及停止清除声音，继续时从原采样位置恢复尚未结束的音。
- 默认中等力度。右侧可设置整列的轻／中／重，也可单独修改选中音符，突出同时弹组合中的旋律音；试听和整谱播放都采用相同设置。
- 选中目标音符，在右侧“音符”页设置击弦 h、勾弦 p 或滑弦；技巧连接到前一颗同弦音，同时弹的其他弦不受影响。新滑弦默认快滑（在两音间隔最后20%滑动），也可选标准、慢滑或自行调整；已保存的滑动时间不改变。技巧目前由用户手动添加，保存后可继续编辑；改动弦号、品位或顺序导致连接不成立时会自动移除并提示。
- 选中主音后，在右侧“音符”页添加短前倚音：填写小音的弦和品位，选择分别拨弦／击弦／勾弦／滑入及提前量。谱上小数字画在实际发声的弦，主音仍落在原拍点；“试听当前位置”也会播放倚音。需要移除时点击“移除”。
- 选中非空弦音符，在同一页选择推弦幅度（四分音、半音、全音）、推到目标的速度和是否回落；选择“无推弦”即可删除。谱面显示推弦箭头，保存和重新打开后保留。倚音与推弦目前手动添加，不参与图片自动识别。
- 先点击起始位置，再按住Shift点击结束位置，可以跨小节连续选段；顶部“批量轻重音”支持当前选段、当前小节、练习范围或全谱。批量及整列设置会统一范围内音符的力度，清除其中的单音力度覆盖，可撤销。
- 力度随乐谱文件保存，旧文件未设置力度时仍为中等。当前通过音量实现，`pp/ff`采样力度层留待后续接入。
- 可撤销和重做；修改自动在本机暂存，切换谱例也会保留修改。
- “保存”直接写入项目下的 `乐谱库/` 文件夹，再次保存更新同一文件，并保留上一次备份。文件在其他窗口改过会拒绝覆盖，可重新打开或另存为。
- “乐谱库”可打开已保存乐谱，也能找回各首乐谱的未保存暂存；顶部可按歌名搜索、筛选最近 7/30/90 天的修改，并按时间或歌名排序。重新打开同一份本地文件或乐谱库中的保存版本时，若存在不同的未保存修改，会先生成独立的“未保存修改（恢复）”暂存，避免覆盖。已保存文件右侧的“删除”会先确认，再把文件及上次备份移到 `乐谱库/.回收站/`；暂存右侧的“删除暂存”只清理浏览器里的恢复副本。
- “另存为”创建独立编曲；“导出”下载含原图的 `.tablens.json`；“打开文件”接受这个文件及已有识别JSON。“打开文件”和“导入谱图”的系统文件窗口由浏览器记住上次使用的文件夹，网页无法指定绝对初始位置；已保存乐谱直接点“乐谱库”打开，其实际完整目录显示在弹窗顶部。

如果想让外部 Agent 直接看谱生成文件，在“导入谱图”窗口下载 AGENT_IMPORT_TEMPLATE.md，或从项目根目录取得它，再与谱图一起交给 Agent；保存它输出的 .json 后，点击顶部“打开文件”导入。这个格式支持弦、品位、先后、同时弹、和弦名、明确标记的上下扫弦、休止与基本节奏。指型图清楚时 Agent 可逐弦写入 notes；只有和弦名时保留符号和待确认位置，不凭名称猜指型。导入时会检查字段与位置，不能确认的音、扫弦方向和节奏保留为待修改。导入后请先看“校对提示”，并手动关联原图；目前不会自动逐音定位原图。

点击“导入谱图”，可选择 PNG/JPG/WebP 或不超过 20MB 的 PDF。PDF 先选页，再把该页渲染成图片；可逐页分析、检查候选，并用“追加到当前谱”按顺序接入多页小节。PDF 原文件不随乐谱保存，选中的页面图像会随乐谱保存供原图对照。“分析图片”仅在本机定位，不调用模型。绿色框是可识别段落，橙色框表示无下方符干、截断或无法可靠定位的段落；这类段落不会猜出音符。勾选需要的段落后，再点击“开始识别”。若某页的 TAB 记号超出现有识别范围，可点“本页作原图，建空小节”，再对照原图手动录入；切换页面前会提醒保存尚未采用的候选结果。

“识图API设置”支持提供商兼容的Chat Completions HTTPS地址及支持图片输入的模型名称；请按提供商的实际配置填写。密钥只保存在本机服务内存中，不写入乐谱、暂存或实验文件，服务重启后重新输入。每次任务最多调用页头一次、每小节分格读取与独立逐弦核对各一次，不自动重试。取消会阻止后续调用，但已发送的请求仍可能计费。

结果先显示候选TAB，点击数字可在左侧高亮原图位置，未点击“作为新谱打开”前不修改当前乐谱。部分失败可重新勾选失败段落再识别。当前成功读取的音符仍需检查；两次读取不一致会明确标出。候选不包含未读取的段落，不能当作完整曲目。

右侧“重新识别当前小节”会框选原图，并允许检查后仅替换这一个小节；其他小节和全谱设置保留。如果识别期间手动修改了目标小节，则阻止替换。打开候选或替换小节均可撤销。原图可随乐谱文件保存，重新打开仍可对照和局部重试。

相邻位置可“合并为同时弹”，同弦冲突会拒绝合并；也可把同时弹中的选中音拆到下一位置。合并时累加已知时值，拆分时各分一半；未知节奏仍保持未知，支持再编辑和撤销。设置拍号后，小节时值不匹配会给提示而不补齐；弱起或不完整片段可勾选允许不足，但超过拍数仍会提示。

本机测试用的两个谱例只覆盖各自已验证的小节，并非完整曲目。图片识别先限定清晰、水平、电脑排版且有下方符干的六线TAB；暂不自动读节奏、休止、多声部或复杂技巧。无符干的长音、被截断的末行和特殊排版需后续扩展，识别精度仍需真实API实验验证。

整体模块与后续顺序见 `ARCHITECTURE.md`。`experiments/` 保留可复用代码和提示词，实验输出与私人样本不上传。

`npm test`、`npm run test:public` 和 `npm run test:layout-pdf` 可在公开仓库的克隆环境运行；`test:public` 需要先启动本地服务和安装 Chrome。其他浏览器测试及部分 Python 识别测试使用未上传的 Duvet/Lullaby 谱图，仅适合放回相应测试素材后的开发环境。浏览器验证使用本机 Chrome，并要求本地服务已启动；这些测试不调用识别 API。

音色扩展入口：`app/web/playback.js` 的 `Player(update, instrument)` 接受可替换的发声函数。未来采样音源接收音高、开始时间、时长及音量，并返回停止函数；循环、节拍器和光标不需要随音源重写。

吉他音源来自 `Guitar.stereo.1644.1/1644stereo/` 的15份 `mf` AIFF录音；原始录音不上传，播放器使用的转换产物随公开仓库提供，每份原始录音可含多个音高。`app/prepare_guitar.py` 使用 NumPy 自动分音、保留来源位置并导出118份44.1kHz/16位/双声道 WAV到 `app/web/audio/guitar/`，不改动原始文件。转换先去除录音中的直流偏移及超低频干扰（20–40Hz平滑过渡），避免干扰污染起音检测和音量归一化。提取时检查下一音高、再次拨弦及持续静音，初步保留最多10秒的实际尾音。`pp` 和 `ff` 力度层暂未接入。自动提取的起音、尾音及听感仍需人工试听；超出某根弦采样范围的音使用最近采样移调。

分音后还会按毫秒级短时能量对齐起音，裁掉前导噪声。前导段足够长时，用它估计底噪并做双声道联动的保守频谱降噪，起音前25毫秒保留原声并平滑过渡，不用硬门限切除尾音。没有可靠噪声参考时只对齐，不强行降噪。采样清单记录 `attackTrimMs` 和 `noiseReduced`；4弦2品此次裁掉约115毫秒前导声。五、六弦随后使用经试听确定的 C 版处理：校准采样响度、增强延音中的清晰音高，压低非谐波杂音，并在尾段平滑淡出；处理结果由 `app/bass_processing.py` 生成，原始 AIFF 不变。音源更新后需刷新页面，释放播放器内存中的旧采样。
